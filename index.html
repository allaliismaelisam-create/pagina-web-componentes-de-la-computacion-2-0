COMPONENTES DE UNA COMPUTADORA

Conoce las partes que hacen funcionar un ordenador

Descubre el interior de un ordenador

Aprende cuáles son sus componentes principales, para qué sirven y cómo funcionan juntos.

1. Procesador (CPU)

El procesador, también conocido como CPU, es uno de los componentes más importantes de una computadora. Se encarga de interpretar y ejecutar las instrucciones de los programas.

Su velocidad se mide en GHz. Cuanto más potente sea el procesador, más rápido podrá realizar determinadas tareas. Es fundamental para jugar, estudiar, trabajar y utilizar aplicaciones.

2. Memoria RAM

La memoria RAM es la encargada de guardar temporalmente los datos que necesita el ordenador mientras está encendido.

Permite tener varios programas abiertos al mismo tiempo. Cuanta más memoria RAM tenga un ordenador, mayor capacidad tendrá para trabajar con varias aplicaciones simultáneamente.

3. Placa base

La placa base es el circuito principal del ordenador. En ella se conectan el procesador, la memoria RAM, la tarjeta gráfica y otros componentes.

Su función principal es permitir que todas las piezas se comuniquen entre sí y funcionen correctamente.

4. Disco duro y SSD

El disco duro y las unidades SSD sirven para almacenar información de forma permanente, incluso cuando apagamos el ordenador.

En ellos guardamos fotografías, vídeos, documentos, videojuegos y el sistema operativo. Los SSD suelen ser mucho más rápidos que los discos duros tradicionales.

5. Tarjeta gráfica (GPU)

La tarjeta gráfica se encarga de procesar y generar las imágenes que vemos en la pantalla.

Es especialmente importante para videojuegos, edición de vídeos, diseño gráfico y aplicaciones que necesitan representar imágenes en alta calidad.

6. Fuente de alimentación

La fuente de alimentación transforma la electricidad de la corriente en la energía que necesitan los diferentes componentes del ordenador.

Es imprescindible porque distribuye la energía necesaria para que todo el equipo funcione correctamente.

7. Sistema de refrigeración

El sistema de refrigeración evita que los componentes alcancen temperaturas demasiado elevadas.

Puede utilizar ventiladores o refrigeración líquida. Es importante para mantener el rendimiento y proteger las piezas del ordenador.
